# Control-de-Cuadres-Eommt
Aplicación web progresiva (PWA) que funciona sin conexión, pensada para auxiliares de venta del Metro de Quito. Permite registrar cada turno por estación, ver el porcentaje de cuadres del mes frente a la meta del 80% y exportar el historial. Proyecto personal en desarrollo con HTML, CSS y JavaScript.
